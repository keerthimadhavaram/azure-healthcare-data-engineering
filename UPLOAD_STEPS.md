# Upload Steps

## Repository Name
Create a public GitHub repository named:

```text
azure-healthcare-data-engineering
```

## Description
Use this description:

```text
Azure healthcare data engineering pipeline with ADF, Databricks-style transformations, Snowflake modeling, medallion architecture, and KPI reporting.
```

## Upload
1. Unzip this package.
2. Open the `azure-healthcare-data-engineering-final` folder.
3. On GitHub, click `Add file` → `Upload files`.
4. Drag all files and folders from inside this folder.
5. Commit message: `Initial commit - Azure Healthcare Data Engineering`
6. Click `Commit changes`.
